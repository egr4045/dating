# 🎮 Party Finder / Quests (Dating App)

Платформа для быстрого поиска напарников для онлайн и оффлайн заданий (квестов). Бэкенд написан на **NestJS + Prisma**, фронтенд реализован на **Vue 3 + Vite**, авторизация и уведомления завязаны на **Telegram Bot API**, а живое общение и мэтчинг происходят через **WebSockets (Socket.io)**.

## 🚀 Быстрый старт (Quick Start)

Для запуска приложения на локальной машине с нуля, выполните следующие шаги:

### 1. Требования
Убедитесь, что у вас установлены:
- Node.js (v18+)
- PostgreSQL (локально или в Docker)

### 2. Запуск Бэкенда
Откройте первый терминал и выполните:
```bash
cd backend
npm install

# Настройка переменных окружения (.env)
В папке `backend/.env` должны быть:
- `DATABASE_URL` — строка подключения к вашей БД.
- `TELEGRAM_BOT_TOKEN` — токен вашего бота.
- `FRONTEND_URL` — (опционально) адрес вашего фронтенда для кнопки возврата в боте (по умолчанию `http://localhost:5173`).
- `JWT_SECRET` — ваш секретный ключ.

Фронтенд теперь **динамически** определяет адрес бэкенда по принципу: `текущий_домен:3000`. Вам не нужно ничего менять в коде при деплое на новый сервер.
npx prisma generate
npx prisma db push

# Если есть сид для базы данных (опционально)
npx prisma db seed

# Запуск сервера
npm run start:dev
```
Сервер запустится на http://localhost:3000. В консоли появится сообщение `🤖 Telegram Бот запущен и слушает команды!`.

### 3. Запуск Фронтенда
Откройте второй терминал и выполните:
```bash
cd frontend
npm install

# Запуск Vite сервера
npm run dev
```
Фронтенд будет доступен по адресу http://localhost:5173.

## 🛠 Структура проекта

- `/backend` — NestJS, Prisma ORM, Socket.io, Telegraf. Отвечает за API ленты, чат в реальном времени, Telegram WebSocket авторизацию и распределение пушей.
- `/frontend` — Свайпер-интерфейс в духе Tinder на Vue 3, Vue Router и InteractJs. Общается с бэкендом через REST API и Socket.io для чатов в реальном времени.

## 🔐 Авторизация

В приложении используется уникальный flow:
1. Фронтенд обращается к бэкенду за одноразовым кодом (UUID).
2. Пользователь нажимает кнопку и переходит в Telegram бота: `t.me/ваша_бота?start=<UUID>`.
3. Бот регистрирует пользователя, генерирует JWT-токен и выпускает пуш о том, что вход успешен.
4. Фронтенд опрашивает статус кода и забирает свой JWT-токен для последующих защищенных запросов в защищенном режиме StatePolling.
5. Для подлкючения к сокетам и выполнения API-запросов используется заголовок `Authorization: Bearer <token>`.
